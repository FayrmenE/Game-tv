# 🎉 Вечер игр — набор party-игр для одной комнаты

Большой экран (ТВ или ноутбук) показывает игровое поле, игроки подключаются
с телефонов через браузер по QR-коду. Без аккаунтов, без интернета (нужна только
локальная Wi-Fi сеть), без платных API и без ИИ.

В наборе:

| Игра | Игроков | Суть |
|---|---|---|
| 👽 **Чужой** | 3–10 | Один игрок видит не тот предмет и сам не знает об этом. Слова, споры, голосование. |
| 🎯 **Снайпер** | 2–10 | На ТВ мелькают картинки — жми кнопку, когда появится цель. Кто быстрее? |
| 🐊 **Крокодил: Личный** | 3–10 | Рисуешь на телефоне, остальные пишут догадки. |
| ⚔️ **Крокодил: Дуэль** | 4–12 | Две команды, два художника рисуют одно слово, угадывают криком. |

Пока комната открыта, идёт **Кубок вечера**: за место в каждой партии начисляются
кубковые очки (1-е место +5, 2-е +3, 3-е +1). Таблица видна в углу ТВ.

## Запуск

Нужен [Node.js](https://nodejs.org) 18 или новее.

```bash
npm install && npm start
```

В консоли появится адрес вида `http://192.168.1.23:3000/tv`.

1. Откройте `http://<адрес>:3000/tv` на компьютере, подключённом к телевизору
   (или `http://localhost:3000/tv` на этом же компьютере).
2. На экране появятся QR-код, код комнаты из 4 букв и меню игр.

## Как подключиться с телефонов

1. Телефоны должны быть **в той же Wi-Fi сети**, что и компьютер с сервером.
2. Отсканируйте QR-код камерой — откроется `http://<LAN-IP>:3000/play?room=XXXX`.
3. Введите имя и нажмите «Войти». **Первый подключившийся становится хостом.**
4. Хост выбирает игру в панели на своём телефоне и нажимает «Начать игру».

Телефон помнит игрока (токен в `localStorage`): после перезагрузки страницы или
потери связи он вернётся на своё место — с теми же очками, ролью и рисунком.

Если телефоны не подключаются:
- проверьте, что телефон не в гостевой сети и не на мобильном интернете;
- разрешите Node.js входящие соединения в брандмауэре (Windows спросит при первом запуске);
- если QR-код ведёт не на тот адрес: `PUBLIC_HOST=192.168.1.23 npm start`;
- другой порт: `PORT=8080 npm start`.

## Хост

Хост (телефон первого игрока) может: выбрать игру и начать, поставить паузу,
выгнать игрока, вернуться в меню, сменить язык (ru/en), темп обсуждения «Чужого»
и цель «Дуэли» (10/15/20 очков). Если хост отключился, хостом становится следующий
подключённый игрок.

После каждой партии — **пьедестал** с титулами и кнопки «Ещё раз» (та же игра,
счёт с нуля), «Другая игра» и «Итоги вечера» (чемпион вечера по Кубку).
Игроки остаются в комнате при смене игры.

На ТВ в левом нижнем углу есть кнопка 🔊: браузеры разрешают звук только после клика.
Звуки (правильно, ошибка, выстрел) синтезируются через Web Audio, без файлов.

## 👽 Чужой (3–10)

| Этап | Что происходит |
|---|---|
| 1. Предмет (10 с) | Случайная сцена и пара похожих предметов. Мирные получают предмет А, Чужой — Б. Картинка видна, пока палец держит «Посмотреть». Один игрок не бывает Чужим два раунда подряд. |
| 2. Слова (2 круга) | Порядок случайный, первым каждый раунд ходит другой игрок. Одно слово до 20 символов, 20 с на ход. Не успел — «—». |
| 3. Обсуждение | (30 с + 10 с × игроков) × темп. Живое голосование, анонимные столбики на ТВ. Все проголосовали и 10 с без изменений — таймер ×3. |
| 4. Последнее слово | За 15 с до конца голоса замораживаются, лидер оправдывается 15 с (при ничьей по 10 с), затем 5 с на переголосование. |
| 5. Итог | Ничья — переголосование 15 с между лидерами; снова ничья — Чужой не пойман. |
| 6. Последний шанс | Пойманный Чужой тапает на телефоне предмет мирных. Угадал — Чужой всё равно побеждает. |

Очки: Чужой не пойман +3; пойман, но угадал +2; пойман и не угадал — мирным по +1;
каждому мирному, указавшему на Чужого в финальном голосовании, +1.
Партия — сколько угодно раундов: хост на итогах раунда нажимает «Следующий раунд»
или «Завершить партию». Хост может один раз за раунд добавить «+30 сек».
Титулы: «Мастер маскировки», «Главный сыщик».

## 🎯 Снайпер (2–10)

- Партия из 10 целей. Перед каждой ТВ 3 с показывает «Ловим: банан» с картинкой,
  затем картинки идут по одной в центре экрана.
- Скорость — от 900 мс на картинку у 1-й цели до 400 мс у 10-й.
- Цель появляется один раз на случайной позиции с 5-й по 15-ю картинку. Около трети
  остальных картинок — похожая приманка (второй предмет пары), остальное — случайные предметы
  из всех сцен.
- На телефоне одна огромная кнопка.
- Время реакции считает сервер: момент нажатия (приход на сервер − ½ RTT телефона)
  минус момент показа цели (отправка на ТВ + ½ RTT ТВ). Перед партией сервер делает
  7 замеров пинга каждого телефона и ТВ и берёт медиану.
- Нажатие засчитывается как попадание, если сделано, пока цель на экране (плюс 350 мс
  после смены картинки — чтобы честно считать реакцию на последних, быстрых целях).
- Очки: 1-й попавший +3, 2-й +2, 3-й +1. Нажатие на любую другую картинку −2 и блокировка
  кнопки на 1 с. После каждой цели ТВ показывает таблицу реакций в миллисекундах.
- Победитель — лидер по очкам, титул «Самый быстрый палец» (+ «Лучшая реакция»).

## 🐊 Крокодил

Общее:
- Холст на телефоне: 6 цветов, 2 толщины, ластик, «отменить», «очистить».
  Штрихи передаются координатами (0…1000) батчами раз в ~50 мс, на ТВ рисунок появляется вживую.
- Словари ru и en по 150 слов на уровень (`data/words.js`): лёгкое ×1, среднее ×1.5, сложное ×2.
- Со второго круга случайно (с вероятностью 60%) выпадает модификатор, очки за ход ×1.5:
  «Одной линией», «Без цветов», «Слепой художник», «Под углом», «Мини». Он крупно
  показывается на ТВ. Если круг всего один (8+ игроков в «Личном»), модификаторы идут со
  второй половины ходов.

### Режим «Личный» (3–10)
- Художник выбирает одно из 3 слов разной сложности (10 с), рисует 80 с.
- На ТВ под рисунком «_ _ _ _»; через 40 и 60 с открывается по случайной букве.
- Остальные пишут догадки сколько угодно раз. Проверка без учёта регистра, ё = е, лишние
  пробелы игнорируются, для слов от 5 букв допускается 1 опечатка (Левенштейн) —
  такая догадка засчитывается с пометкой «Почти!».
- Неправильные догадки всплывают на ТВ с именем автора. Угадавший подсвечивается, слово
  остаётся скрытым, писать он больше не может.
- Ход кончается, когда угадали все или вышло время: ТВ показывает слово, рисунок и очки.
- Очки угадавшим по порядку 10 / 8 / 6 / дальше по 4; художнику 3 за каждого угадавшего.
  Множители сложности и модификатора — ко всем очкам хода (с округлением).
- Каждый рисует 2 раза (при 8+ игроках — 1 раз).
- В конце все голосуют за самую смешную неправильную догадку партии.
- Титулы: «Пикассо», «Экстрасенс», «Мимо кассы».

### Режим «Дуэль» (4–12)
- Автоматическое деление на 2 команды (Красные и Синие); хост может перекинуть игрока.
- Каждый ход от каждой команды рисует по художнику (по кругу), оба получают одно и то же
  среднее слово и рисуют одновременно 90 с. ТВ разделён на две половины.
- Угадывают вслух; у остальных на телефоне «Смотри на экран и кричи!».
- У художника рядом с холстом кнопка «Угадали!». Сервер фиксирует, кто нажал первым,
  его команда выигрывает ход (+3, с модификатором ×1.5 → 5).
- После нажатия ТВ показывает слово и команду. 5 с у хоста есть кнопка «Отменить»: ход
  продолжается с оставшимся временем, а нажавший художник 10 с не может нажать снова.
- Никто не угадал за 90 с — 0. Победа — первая команда с 15 очками (настройка 10/15/20).
  Счёт команд всё время показан как гонка по дорожке.

## Тестовый режим с ботами

Откройте `http://localhost:3000/tv?bots=5` — в комнату добавятся 5 ботов.
Подключите один телефон (он станет хостом) и запускайте любую игру. Ботов можно
добавить и из панели хоста в меню («Добавить бота»).

- **Чужой:** боты смотрят предмет, пишут слова, голосуют (мирные с шансом 50% «чуют» Чужого).
- **Снайпер:** жмут на цель с реакцией 250–600 мс, иногда ошибаются на приманке.
- **Крокодил «Личный»:** бот-художник рисует случайные линии; боты пишут 1–3 неправильных
  слова и с вероятностью 65% угадывают (иногда с опечаткой).
- **Крокодил «Дуэль»:** боты делятся на команды, бот-художник рисует случайные линии и
  жмёт «Угадали!» через случайные 20–80 с.

Отладочные переменные окружения:
- `TIME_SCALE=0.3` — ускорить таймеры фаз (0.3 ≈ в 3 раза быстрее);
- `MIN_PLAYERS=2` — минимум игроков для всех игр;
- `?fresh=1` в адресе телефона — отдельный игрок в этой вкладке (для тестов в одном браузере).

## Устройство проекта

```
server.js                 Запуск: Express + socket.io
lib/platform.js           Ядро: комнаты, игроки, хост, токены, таймер с паузой, планировщик,
                          пинг, меню, пьедестал, Кубок вечера, боты
lib/util.js               Утилиты: перемешивание, медиана, Левенштейн, нормализация слов, LAN IP
games/index.js            Реестр игр (пункты меню)
games/alien.js            Чужой
games/sniper.js           Снайпер
games/crocodile.js        Крокодил (solo / duel)
data/scenes.json          Сцены: 3 × 24 предмета, координаты, пары похожих предметов
data/words.js             Словари Крокодила (ru, en × 3 уровня × 150 слов)
public/tv.html, play.html Страницы /tv и /play
public/js/tv.js, play.js  Оболочка ТВ и телефона (меню, пьедестал, панель хоста)
public/js/art.js          SVG-иллюстрации: 72 предмета и 3 фона
public/js/i18n.js         Единый файл переводов (ru + en)
public/js/canvas.js       Холст Крокодила (рисование и отрисовка штрихов)
public/js/sound.js        Звуки через Web Audio
public/games/*.tv.js      Экран ТВ каждой игры
public/games/*.play.js    Экран телефона каждой игры
scripts/check-scenes.js   Проверка данных: npm run check
```

### Интерфейс модуля игры

`games/<id>.js` экспортирует `create(api, opts)`, который возвращает объект:

| Метод | Назначение |
|---|---|
| `start()` | начало партии |
| `action(player, type, data, now)` | действие игрока с телефона |
| `host(type, data)` | команда хоста, специфичная для игры |
| `tick(now)` | вызывается каждые 100 мс (кроме паузы) |
| `tvView()` | состояние для ТВ — **без секретов** до раскрытия |
| `playerView(player)` | состояние для конкретного телефона (его секреты — только ему) |
| `join / leave / tvJoin` | переподключение игрока, уход игрока, подключение ТВ |
| `bot(player, view)` | поведение тестового бота |
| `destroy()` | уборка |

`api` даёт таймер фазы (`setTimer`, с паузой), точный планировщик `later(ms)`, отправку
событий ТВ/игроку, звуки, замер пинга и `finish(result)` — конец партии с ранжированием
и титулами (платформа сама покажет пьедестал и начислит Кубок).
