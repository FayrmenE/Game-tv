# 🎉 Вечер игр — набор party-игр для одной комнаты

Большой экран (ТВ или ноутбук) показывает игровое поле, игроки подключаются
с телефонов через браузер по QR-коду. Без аккаунтов, без интернета (нужна только
локальная Wi-Fi сеть), без платных API и без ИИ.

В наборе:

| Игра | Игроков | Суть |
|---|---|---|
| 👽 **Чужой** | 3–10 | Один игрок видит не тот предмет и сам не знает об этом. Слова, споры, голосование. |
| 🎯 **Снайпер** | 2–10 | На ТВ мелькают картинки — жми кнопку, когда появится цель. Кто быстрее? |
| 🐊 **Крокодил: Личный** | 3–10 | Рисуешь на телефоне, остальные пишут догадки. |
| ⚔️ **Крокодил: Дуэль** | 4–12 | Две команды, два художника рисуют одно слово, угадывают криком. |
| 🚢 **Морской бой** | 2 | Классическая дуэль на двоих; остальные в комнате — зрители на ТВ. Можно играть с ботом. |
| 🧰 **Сундуки** | 3–12 | Смотритель знает, что в сундуке, и рассказывает — правду или нет. Тайные ставки, блеф, Вор и Мимик. |
| 🖍️ **Каракули** | 3–8 | Рисуешь свою смешную фразу, сочиняешь обманки к чужим рисункам и ищешь правду. |

Пока комната открыта, идёт **Кубок вечера**: за место в каждой партии начисляются
кубковые очки (1-е место +5, 2-е +3, 3-е +1). Таблица видна в углу ТВ.

## Запуск

### Проще всего (Windows)

Скачайте папку с игрой и дважды кликните **«Запустить Вечер игр.cmd»**. Файл сам проверит
Node.js (если его нет — предложит установить через winget или откроет страницу загрузки),
при первом запуске установит компоненты и откроет экран ТВ в браузере.
На macOS / Linux то же делает `start.command` / `start.sh`.

### Один файл .exe без установки Node.js

GitHub сам собирает `Vecher-igr.exe` при каждом обновлении ветки: вкладка **Actions** →
«Сборка exe для Windows» → последний запуск → **Artifacts** → `Vecher-igr-windows`.
Распакуйте и запустите двойным кликом — браузер откроется сам. Рядом с exe появится файл
`.party-save.json` с Кубком вечера. Собрать вручную: `npm run build:exe`.

### Из командной строки

Нужен [Node.js](https://nodejs.org) 18 или новее.

```bash
npm install && npm start
```

В консоли появится адрес вида `http://192.168.1.23:3000/tv`.

1. Откройте `http://<адрес>:3000/tv` на компьютере, подключённом к телевизору
   (или `http://localhost:3000/tv` на этом же компьютере).
2. На экране появятся QR-код, код комнаты из 4 букв и меню игр.

## Как подключиться с телефонов

1. Телефоны должны быть **в той же Wi-Fi сети**, что и компьютер с сервером.
2. Отсканируйте QR-код камерой — откроется `http://<LAN-IP>:3000/play?room=XXXX`.
3. Введите имя и нажмите «Войти». **Первый подключившийся становится хостом.**
4. Хост выбирает игру в панели на своём телефоне и нажимает «Начать игру».

Телефон помнит игрока (токен в `localStorage`): после перезагрузки страницы или
потери связи он вернётся на своё место — с теми же очками, ролью и рисунком.

Если телефоны не подключаются, откройте **`http://<адрес>:3000/check`** — страница диагностики
покажет адреса компьютера в сети, QR, пинг, проверит звук и возможности браузера. Ещё советы:
- проверьте, что телефон не в гостевой сети и не на мобильном интернете;
- разрешите Node.js входящие соединения в брандмауэре (Windows спросит при первом запуске);
- если QR-код ведёт не на тот адрес: `PUBLIC_HOST=192.168.1.23 npm start`;
- другой порт: `PORT=8080 npm start`.

## Экраны и браузеры

Интерфейс ТВ масштабируется по меньшей стороне окна: одинаково выглядит на ТВ 4K, мониторе
1920×1080, ноутбуке с маленьким окном браузера и на вертикальном экране. Телефонный экран
рассчитан на ширину от 320 px, вертикально и горизонтально (в горизонтальном Крокодиле
инструменты справа от холста), учитывает вырезы экрана iPhone. Стили — в `public/responsive.css`.

## Атмосфера и удобства

- **Как играть.** Перед первой партией каждой игры ТВ показывает правила в 4 шага
  и ждёт, пока хост нажмёт «Начать игру» (повторить правила — кнопка «Правила» в меню).
- **Свой аватар.** При входе можно нарисовать себя пальцем — рисунок станет аватаром на весь вечер
  (поменять — кнопка «Нарисовать аватар» на телефоне в меню).
- **Реакции.** Внизу телефона — 😂🔥😱👏🤔😍💩🤯: эмодзи всплывают на ТВ с именем
  (скрыты там, где мешают: у художника, на кнопке Снайпера, при просмотре предмета).
- **Свой стиль у каждой игры**, заставки при смене фаз, отсчёт «3-2-1» в Снайпере, барабанная дробь
  при раскрытии Чужого, тиканье в последние 5 секунд, конфетти на пьедестале.
- **Крупный текст** и **высокий контраст** для ТВ — в настройках хоста.
- **Кубок вечера сохраняется на диск** (`.party-save.json`): если компьютер перезагрузился или окно
  закрыли, после перезапуска телевизор и телефоны вернутся в ту же комнату с тем же счётом
  (сохранение живёт 12 часов; отключить — `NO_SAVE=1`).

## Хост

Хост (телефон первого игрока) может: выбрать игру и начать, поставить паузу,
выгнать игрока, вернуться в меню, сменить язык (ru/en), темп обсуждения «Чужого»
и цель «Дуэли» (10/15/20 очков). Если хост отключился, хостом становится следующий
подключённый игрок.

После каждой партии — **пьедестал** с титулами и кнопки «Ещё раз» (та же игра,
счёт с нуля), «Другая игра» и «Итоги вечера» (чемпион вечера по Кубку).
Игроки остаются в комнате при смене игры.

На ТВ в левом нижнем углу есть кнопка 🔊: браузеры разрешают звук только после клика.
Звуки — бесплатные наборы Kenney (лицензия CC0: Interface Sounds, Impact Sounds, Music Jingles)
в `public/sfx/*.mp3`; если файл не загрузился, звук синтезируется через Web Audio.

## 👽 Чужой (3–10)

| Этап | Что происходит |
|---|---|
| 1. Предмет (10 с) | Случайная сцена и пара похожих предметов. Мирные получают предмет А, Чужой — Б. Картинка видна, пока палец держит «Посмотреть». Один игрок не бывает Чужим два раунда подряд. |
| 2. Слова (2 круга) | Порядок случайный, первым каждый раунд ходит другой игрок. Одно слово до 16 символов, 20 с на ход. Не успел — «—». |
| 3. Обсуждение | (30 с + 10 с × игроков) × темп. Живое голосование, анонимные столбики на ТВ. Все проголосовали — до конца обсуждения остаётся 10 с. |
| 4. Последнее слово | За 15 с до конца голоса замораживаются, лидер оправдывается 15 с (при ничьей по 10 с), затем 5 с на переголосование. |
| 5. Итог | Ничья — переголосование 15 с между лидерами; снова ничья — Чужой не пойман. |
| 6. Последний шанс | Пойманный Чужой тапает на телефоне предмет мирных. Угадал — Чужой всё равно побеждает. |

Очки: Чужой не пойман +3; пойман, но угадал +2; пойман и не угадал — мирным по +1;
каждому мирному, указавшему на Чужого в финальном голосовании, +1.
Партия — сколько угодно раундов: хост на итогах раунда нажимает «Следующий раунд»
или «Завершить партию». Хост может один раз за раунд добавить «+30 сек».
Титулы: «Мастер маскировки», «Главный сыщик».

## 🧰 Сундуки (3–12)

У каждого 100 монет. Смотритель — по очереди, в порядке входа в комнату; круг — каждый побывал
Смотрителем один раз. Сундуков за партию = игроков × кругов. Колода из 40 сундуков:
+10×5, +20×5, +30×3, +50×2, Пусто×4, −10×5, −20×5, −30×3, Вор×4, Мимик×4.

1. **Осмотр** — содержимое видит только телефон Смотрителя («Готов» или 10 с).
2. **Обсуждение** — 40 или 30 с, Смотритель рассказывает (может врать), может «Пропустить таймер».
3. **Ставки** — 15 с, все кроме Смотрителя и банкротов тайно ставят 0…свои монеты (0 = пас,
   кнопки +1/+5/+10/−5, «Пас», «Ва-банк»; менять можно до конца таймера).
4. **Раскрытие** — на ТВ переворачиваются все ставки, затем открывается сундук.

Единственная максимальная ставка покупает сундук: деньги — Смотрителю (в жёстком режиме — половина
вниз, остальное сгорает). Ничья на максимуме — сундук сгорает, никто не платит. Все спасовали —
сундук бесплатно Смотрителю. **Вор** — получатель выбирает, у кого украсть до 15 монет (15 с, иначе
случайно). **Мимик** — получатель платит свою ставку ещё раз (бесплатный — без эффекта). Монеты не
уходят ниже 0; банкрот не ставит, но остаётся Смотрителем в свою очередь и оживает, получив монеты.
Конец: после всех кругов (больше монет; при равенстве — кто больше заработал Смотрителем), досрочно —
если деньги остались у одного, или ничья, если у всех 0. Итоги: «Лучший Смотритель»,
«Самая дорогая ошибка», «Главный пасовщик».

Настройки в панели хоста, когда в меню выбраны «Сундуки»: кругов 3/2, обсуждение 40/30 с,
жёсткий режим. Вся логика раунда — чистые функции в `games/chests-logic.js`, тесты: `npm test`.

## 🖍️ Каракули (3–8)

Суть — не угадать, а **обмануть**: чтобы все поверили, что твоя подпись и есть задание художника.

- Все одновременно рисуют на телефонах своё задание, 80 с, честно — чтобы было понятно.
  Задание видит только автор; одно можно поменять до первого штриха. Пул (`data/phrases.js`):
  150 странных сочетаний («поющий водолаз», «странное время», «квантовый борщ»…)
  и 100 сложных, но понятных слов («прокрастинация», «ностальгия», «невесомость»…), ru/en.
- Рисунки по очереди выходят на ТВ. Все, кроме автора, пишут свою подпись (45 с) — так, чтобы
  её приняли за настоящее задание. Если написать само задание, игра попросит придумать другое.
- Голосование (25 с): настоящее задание вперемешку с подписями, за свою голосовать нельзя.
  Если подписей мало, игра добавляет варианты из пула.
- Все варианты оформлены одинаково (с большой буквы, без точки), порядок случайный.
- Раскрытие: варианты открываются по одному в том же порядке, что при голосовании, — кто за что
  голосовал и чья подпись; правда может оказаться где угодно.
- **Очки:** нашёл правду +300; автору подписи +200 за каждого, кто в неё поверил; художнику
  +100 за каждого угадавшего (если угадали все — только +100: рисунок был слишком очевидным). Каждый рисует 2 раза (при 6+ игроках — 1).
  Титулы «Главный обманщик», «Зоркий глаз».

## 🚢 Морской бой (2 игрока)

- Поле 10×10 (А–К, 1–10), флот: 1×4, 2×3, 3×2, 4×1. Корабли не касаются даже углами —
  правило проверяют и телефон, и сервер.
- **Расстановка** (2 мин): флот сразу расставлен случайно. Корабль перетаскивается пальцем —
  под ним подсвечиваются клетки: зелёные — можно поставить, красные — нельзя. Тап по кораблю —
  выбрать, «Повернуть» — развернуть, «Случайно» — новая расстановка, «Готов!».
  Время вышло — играют с тем, что стоит.
- После каждого попадания 4 клетки по диагонали от него помечаются сами: там корабля быть не может
  (корабли прямые и не касаются углами). Больше ничего не отмечается — это не подсказка.
- **Бой**: по очереди тапаете клетку на поле соперника (30 с на выстрел, иначе — выстрел наугад).
  Попал — стреляешь ещё раз, мимо — ход сопернику. Вокруг потопленного корабля клетки
  помечаются сами. Кто первым потопит весь флот — победил.
- ТВ показывает оба моря в «тумане»: только выстрелы и потопленные корабли (обломки с огнём).
  Над морем каждого игрока стоит его корабль; в свой ход он стреляет через экран в море соперника: снаряд летит по дуге в клетку, затем взрыв
  или всплеск и крупно — результат («Ж1 — потопил 2-палубный!»). Флоты раскрываются в конце.
- Корабли нарисованы в `public/js/ships.js` (SVG, по размеру клеток). Чтобы поставить свои
  картинки — положите `public/img/ships/ship1…4.png` и `wreck1…4.png` и включите `SHIPS.useImages`.
- Играет хост и первый подключившийся человек (иначе — бот); хост может «Сменить соперника»
  до начала боя. Остальные — зрители. Бот добивает подбитые корабли и стреляет «шахматкой».
- Титулы: «Адмирал», «Меткий глаз» (лучший процент попаданий).

## 🎯 Снайпер (2–10)

- Партия из 10 целей. Перед каждой ТВ 3 с показывает «Ловим: банан» с картинкой,
  затем картинки идут по одной в центре экрана.
- Скорость — от 900 мс на картинку у 1-й цели до 400 мс у 10-й.
- Цель появляется один раз на случайной позиции с 5-й по 15-ю картинку. Около трети
  остальных картинок — похожая приманка (второй предмет пары), остальное — случайные предметы
  из всех сцен.
- На телефоне одна огромная кнопка.
- Время реакции считает сервер: момент нажатия (приход на сервер − ½ RTT телефона)
  минус момент показа цели (отправка на ТВ + ½ RTT ТВ). Перед партией сервер делает
  7 замеров пинга каждого телефона и ТВ и берёт медиану.
- Нажатие засчитывается как попадание, если сделано, пока цель на экране (плюс 350 мс
  после смены картинки — чтобы честно считать реакцию на последних, быстрых целях).
- Очки: 1-й попавший +3, 2-й +2, 3-й +1. Нажатие на любую другую картинку −2 и блокировка
  кнопки на 1 с. После каждой цели ТВ показывает таблицу реакций в миллисекундах.
- Победитель — лидер по очкам, титул «Самый быстрый палец» (+ «Лучшая реакция»).

## 🐊 Крокодил

Общее:
- Холст на телефоне: 7 цветов (с белым), 2 толщины, ластик, «отменить», «очистить».
  Штрихи передаются координатами (0…1000) батчами раз в ~50 мс, на ТВ рисунок появляется вживую.
- Словари ru и en по 150 слов на уровень (`data/words.js`): лёгкое ×1, среднее ×1.5, сложное ×2.
- **Свои слова**: хост вписывает их в настройках (через запятую, до 200). «Вперемешку» — в «Личном»
  появляется четвёртый вариант «своё ×1.5», в «Дуэли» каждое второе слово своё; «Только свои» — все
  слова из вашего списка.
- Со второго круга случайно (с вероятностью 60%) выпадает модификатор, очки за ход ×1.5:
  «Одной линией», «Без цветов», «Слепой художник», «Под углом», «Мини». Он крупно
  показывается на ТВ. Если круг всего один (8+ игроков в «Личном»), модификаторы идут со
  второй половины ходов.

### Режим «Личный» (3–10)
- Художник выбирает одно из 3 слов разной сложности (10 с), рисует 80 с.
- На ТВ под рисунком «_ _ _ _»; через 40 и 60 с открывается по случайной букве.
- Остальные пишут догадки сколько угодно раз. Проверка без учёта регистра, ё = е, лишние
  пробелы игнорируются, для слов от 5 букв допускается 1 опечатка (Левенштейн) —
  такая догадка засчитывается с пометкой «Почти!».
- Неправильные догадки всплывают на ТВ с именем автора. Угадавший подсвечивается, слово
  остаётся скрытым, писать он больше не может.
- Ход кончается, когда угадали все или вышло время: ТВ показывает слово, рисунок и очки.
- Очки угадавшим по порядку 10 / 8 / 6 / дальше по 4; художнику 3 за каждого угадавшего.
  Множители сложности и модификатора — ко всем очкам хода (с округлением).
- Каждый рисует 2 раза (при 8+ игроках — 1 раз).
- В конце все голосуют за самую смешную неправильную догадку партии.
- Титулы: «Пикассо», «Экстрасенс», «Мимо кассы».

### Режим «Дуэль» (4–12)
- Автоматическое деление на 2 команды (Красные и Синие); хост может перекинуть игрока.
- Каждый ход от каждой команды рисует по художнику (по кругу), оба получают одно и то же
  среднее слово и рисуют одновременно 90 с. ТВ разделён на две половины.
- Угадывают вслух; у остальных на телефоне «Смотри на экран и кричи!».
- У художника рядом с холстом кнопка «Угадали!». Сервер фиксирует, кто нажал первым,
  его команда выигрывает ход (+3, с модификатором ×1.5 → 5).
- После нажатия ТВ показывает слово и команду. 5 с у хоста есть кнопка «Отменить»: ход
  продолжается с оставшимся временем, а нажавший художник 10 с не может нажать снова.
- Никто не угадал за 90 с — 0. Победа — первая команда с 15 очками (настройка 10/15/20).
  Счёт команд всё время показан как гонка по дорожке.

## Тестовый режим с ботами

Откройте `http://localhost:3000/tv?bots=5` — в комнату добавятся 5 ботов.
Боты играют и в настоящих партиях: например, вдвоём можно сыграть в «Чужого» с ботом-подозреваемым
(«Добавить бота» в панели хоста). Бот честный: знает только свой предмет, пишет подходящие к нему
слова (`data/hints.js`) и голосует за того, чьи слова хуже подходят.
Подключите один телефон (он станет хостом) и запускайте любую игру. Ботов можно
добавить и из панели хоста в меню («Добавить бота»).

- **Чужой:** боты смотрят предмет, пишут подсказки к своему предмету, голосуют по словам.
- **Снайпер:** жмут на цель с реакцией 250–600 мс, иногда ошибаются на приманке.
- **Крокодил «Личный»:** бот-художник рисует случайные линии; боты пишут 1–3 неправильных
  слова и с вероятностью 65% угадывают (иногда с опечаткой).
- **Сундуки:** бот-Смотритель жмёт «Готов», боты ставят случайно (треть — пас), Вор крадёт у самого богатого.
- **Крокодил «Дуэль»:** боты делятся на команды, бот-художник рисует случайные линии и
  жмёт «Угадали!» через случайные 20–80 с.

Отладочные переменные окружения:
- `TIME_SCALE=0.3` — ускорить таймеры фаз (0.3 ≈ в 3 раза быстрее);
- `MIN_PLAYERS=2` — минимум игроков для всех игр;
- `?fresh=1` в адресе телефона — отдельный игрок в этой вкладке (для тестов в одном браузере).

### Интерфейс модуля игры

`games/<id>.js` экспортирует `create(api, opts)`, который возвращает объект:

| Метод | Назначение |
|---|---|
| `start()` | начало партии |
| `action(player, type, data, now)` | действие игрока с телефона |
| `host(type, data)` | команда хоста, специфичная для игры |
| `tick(now)` | вызывается каждые 100 мс (кроме паузы) |
| `tvView()` | состояние для ТВ — **без секретов** до раскрытия |
| `playerView(player)` | состояние для конкретного телефона (его секреты — только ему) |
| `join / leave / tvJoin` | переподключение игрока, уход игрока, подключение ТВ |
| `bot(player, view)` | поведение тестового бота |
| `destroy()` | уборка |

`api` даёт таймер фазы (`setTimer`, с паузой), точный планировщик `later(ms)`, отправку
событий ТВ/игроку, звуки, замер пинга и `finish(result)` — конец партии с ранжированием
и титулами (платформа сама покажет пьедестал и начислит Кубок).
