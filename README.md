# 👽 Чужой — party-игра для одной комнаты

Большой экран (ТВ или ноутбук) показывает игровое поле, игроки подключаются
с телефонов через браузер по QR-коду. Без аккаунтов, без интернета (нужна только
локальная Wi-Fi сеть), без платных API и без ИИ.

Один из игроков (Чужой) получает не тот предмет, что все остальные, и **сам об
этом не знает**. Игроки по очереди называют по слову о своём предмете, спорят и
голосуют. Мирные должны вычислить Чужого, а Чужой — не выдать себя.

## Запуск

Нужен [Node.js](https://nodejs.org) 18 или новее.

```bash
npm install && npm start
```

В консоли появится адрес вида `http://192.168.1.23:3000/tv`.

1. Откройте `http://<адрес>:3000/tv` на компьютере, подключённом к телевизору
   (или просто `http://localhost:3000/tv` на этом же компьютере).
2. На экране появятся QR-код и код комнаты из 4 букв.

## Как подключиться с телефонов

1. Телефоны должны быть подключены **к той же Wi-Fi сети**, что и компьютер с сервером.
2. Отсканируйте QR-код камерой телефона — откроется страница
   `http://<LAN-IP>:3000/play?room=XXXX`. Можно ввести этот адрес вручную.
3. Введите имя и нажмите «Войти». **Первый подключившийся становится хостом.**
4. Когда наберётся 4–10 игроков, хост нажимает «Начать игру» на своём телефоне.

Если телефоны не подключаются:

- проверьте, что телефон не в гостевой сети / не на мобильном интернете;
- разрешите Node.js входящие соединения в брандмауэре (Windows спросит при первом запуске);
- если у компьютера несколько сетевых адаптеров и QR-код ведёт не туда, задайте адрес
  вручную: `PUBLIC_HOST=192.168.1.23 npm start`;
- другой порт: `PORT=8080 npm start`.

Если телефон потерял связь или страницу перезагрузили, он вернётся в игру
автоматически (в той же вкладке браузера).

## Правила раунда

| Этап | Что происходит |
|---|---|
| 1. Предмет (10 с) | Случайная сцена и случайная пара похожих предметов. Мирные получают предмет А, Чужой — предмет Б. Картинка видна только пока палец держит кнопку «Посмотреть». На ТВ — сцена и галочки «посмотрел». Один игрок не бывает Чужим два раунда подряд. |
| 2. Слова (2 круга) | Порядок случайный, первым каждый раунд ходит другой игрок. Одно слово без пробелов, до 20 символов, 20 с на ход. Слово сразу появляется на ТВ под аватаркой; не успел — «—». |
| 3. Обсуждение | Длительность = (30 с + 10 с × игроков) × темп (быстрый 0.7 / обычный 1 / длинный 1.5). Тап по игроку = голос, менять можно сколько угодно. На ТВ растут анонимные столбики. Последние 10 с таймер красный. Если все проголосовали и 10 с никто не менял голос — таймер ускоряется (×3). |
| 4. Последнее слово | За 15 с до конца голоса замораживаются. Лидер получает 15 с на оправдание (при ничьей — по 10 с каждому). Затем 5 с на переголосование, и голоса замораживаются окончательно. |
| 5. Итог | При ничьей — переголосование 15 с только между лидерами; снова ничья — Чужой не пойман. На ТВ голоса переворачиваются по одному, затем показывается Чужой. |
| 6. Последний шанс | Если Чужого поймали, на его телефоне появляется вся сцена: он тапает предмет, который, по его мнению, был у мирных (30 с). Угадал — Чужой всё равно побеждает. |

Пока Чужой делает последний выбор, предметы на ТВ скрыты (иначе он просто подсмотрит
ответ) и показываются в итогах раунда.

**Очки:** Чужой не пойман — Чужому +3; пойман, но угадал предмет — Чужому +2;
пойман и не угадал — каждому мирному +1. Кроме того, каждый мирный, который в
финальном голосовании указал на Чужого, получает +1.

**Хост** (телефон первого игрока) может: начать игру / следующий раунд, поставить
паузу, один раз за раунд добавить «+30 сек», выгнать игрока, вернуть всех в лобби,
сменить язык (ru/en) и темп обсуждения. Если хост отключился, хостом становится
следующий подключённый игрок.

## Устройство проекта

```
server.js              Express + socket.io, вся логика игры (комнаты, фазы, таймеры, голоса)
data/scenes.json       Описание сцен: id, название (ключ перевода), 24 предмета
                       (номер, id, ключ названия, координаты x/y, размер), список пар
public/tv.html         Экран ТВ        → /tv
public/play.html       Экран телефона  → /play
public/js/art.js       Все иллюстрации: 72 предмета и 3 фона, нарисованные в SVG
public/js/i18n.js      Единый файл переводов (ru + en): интерфейс, сцены, предметы
public/js/common.js    Общие утилиты (таймер, аватарки)
public/js/tv.js        Логика экрана ТВ
public/js/play.js      Логика экрана телефона
public/style.css       Стили
scripts/check-scenes.js  Проверка данных сцен: npm run check
```

### Сцены и предметы

Три сцены — «Кухня», «Пляж», «Вокзал», по 24 пронумерованных предмета и 8–9 пар
похожих предметов в каждой (например: красная/синяя кружка, банан/кукуруза,
кот/собака, часы/сковорода; мяч/спасательный круг, чайка/самолёт, арбуз/пицца;
чемодан/портфель, билет/купюра, голубь/ворона, шляпа/кепка).

Каждый предмет — отдельная функция в `art.js`, рисующая его в координатах 100×100.
Поэтому один и тот же рисунок:

- показывается крупно на телефоне — `ART.itemSvg(id)`;
- подсвечивается/увеличивается на ТВ — группа `<g id="item-<id>" class="scene-item">`
  внутри `ART.sceneSvg(scene)`;
- кликабелен на телефоне при финальном угадывании — атрибут `data-item="<id>"`.

Названия сцен и предметов хранятся в `i18n.js` (ключи `scene.*` и `item.*`), в
`scenes.json` указаны только ключи — так все строки остаются в одном файле переводов.

Чтобы добавить сцену: нарисуйте предметы в `art.js` (`ITEMS`) и фон (`BACKGROUNDS`),
опишите сцену в `data/scenes.json`, добавьте переводы в `i18n.js` и запустите
`npm run check`.

### Отладка

- `MIN_PLAYERS=2 npm start` — разрешить старт с меньшим числом игроков.
- `TIME_SCALE=0.3 npm start` — ускорить все таймеры (0.3 = в ~3 раза быстрее).
- Несколько «телефонов» можно открыть в разных вкладках одного браузера —
  каждая вкладка считается отдельным игроком.
