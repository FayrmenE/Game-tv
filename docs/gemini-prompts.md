# Промпты для Gemini: новые картинки предметов

Каждый промпт — один лист 6×4 = 24 предмета для одной сцены. Отправляйте по одному, сохраняйте картинку как есть (PNG, без обрезки) и присылайте мне вместе с названием сцены.

## Кухня (kitchen)

```
Create ONE square image, 2048×2048 px: a sprite sheet of 24 separate game icons arranged in a strict grid of 6 columns × 4 rows (each cell exactly 1/6 of the width and 1/4 of the height).

STYLE (must be identical for every icon):
- bright flat vector illustration, cheerful and cute, for a family party game shown on a TV
- thick dark navy outline (#2d2a3e) around every object, about 3% of the icon size, rounded line ends
- flat fills with ONE soft shade and one small white highlight; no gradients, no textures, no realistic shading
- saturated friendly colors (red #e63946, blue #3a86ff, yellow #ffd23f, green #52b788, orange #fb8b24, teal #2ec4b6, purple #8e5bd9)
- front or 3/4 view, simple readable silhouette — must be recognisable from a sofa 3 meters away

LAYOUT RULES (important — the sheet will be cut automatically):
- pure plain white background (#FFFFFF) everywhere, no frames, no cell borders, no shadows on the ground
- one object per cell, centered, filling about 75% of the cell, never touching or crossing into neighbouring cells
- NO text, NO numbers, NO labels, NO watermark anywhere
- keep the exact order below: left to right, top to bottom

SIMILAR PAIRS: some objects come in look-alike pairs (listed below). Make each pair similar in size, shape and color family, but clearly distinguishable on a careful look (e.g. red vs blue mug of the same shape).

THEME: kitchen objects.

OBJECTS IN ORDER:
Row 1: 1. Wall clock, 2. Potted plant, 3. Red mug, 4. Salt shaker, 5. Frying pan, 6. Egg
Row 2: 7. Kettle, 8. Lemon, 9. Fork, 10. Coffee pot, 11. Blue mug, 12. Cheese
Row 3: 13. Bread, 14. Apple, 15. Banana, 16. Spoon, 17. Tomato, 18. Pepper shaker
Row 4: 19. Cat, 20. Carrot, 21. Corn, 22. Orange, 23. Rolling pin, 24. Dog

LOOK-ALIKE PAIRS: Red mug / Blue mug; Banana / Corn; Cat / Dog; Wall clock / Frying pan; Kettle / Coffee pot; Apple / Tomato; Salt shaker / Pepper shaker; Fork / Spoon; Lemon / Orange
```
